# PhoneSimulator 可视化配置编辑器

这是 PhoneSimulator 推荐使用的内容与剧情编辑工具。它把普通手机内容显示为表格或消息序列，把剧情流程显示为类似蓝图的节点和连线，使用者不需要直接编写 JSON。

编辑器可以新建、打开和保存 `.phone-project.json` 项目文件，也可以一次性导入旧版 Excel，最后导出手机网页使用的 `content.json` 与 `story.json`。

## 启动编辑器

需要 Node.js 22。在项目根目录运行：

```powershell
Set-Location .\config-editor
npm install
npm run dev
```

打开终端显示的本地地址。结束使用时，在终端按 `Ctrl + C`。

如果只是检查编辑器能否完整构建，可以运行：

```powershell
npm run build
```

## 推荐工作流程

1. 首次打开或点击“新建”，载入内置的通用模板。
2. 编辑基础设置、手机内容、消息与对白。
3. 在剧情流程中创建节点并连接分支。
4. 修正底部问题列表中的红色错误。
5. 点击“保存”或“另存为”，保存 `.phone-project.json`。
6. 点击“导出 JSON”，把 `content.json` 与 `story.json` 写入 `phone-simulator/src/data/`。
7. 在 `phone-simulator/` 运行 `npm run dev` 预览，或运行 `npm run build` 检查完整构建。

编辑器内置模板保留通用基础设置、桌面应用和微信玩家资料，不包含示例联系人、文案或剧情。模板不会随着旧 Excel 或当前运行时 JSON 自动变化。

## 界面说明

- 左侧“配置分类”：切换基础设置、内容资源、通信与日程、微信内容、消息与对白和剧情流程。
- 中间区域：普通内容使用表格，聊天和对白使用序列，剧情使用节点画布。
- 右侧“详细设置”：编辑当前内容或节点的完整字段。
- 底部“问题列表”：显示缺少必填项、重复 ID、失效引用和剧情连接问题。
- 顶部“中文 / 中英对照 / JSON 字段”：切换字段显示方式，不会改变作品数据。
- “查看 JSON”：只读查看当前内容，不在这里直接修改。

## 编辑基础设置和普通内容

“基础设置”包含网页名称、手机尺寸、锁屏密码、手机主人、壁纸、天气和桌面参数。其他分类以表格展示相册、备忘录、联系人、邮件、地图、微信联系人等内容。

常用操作：

- 点击“新建”下拉菜单创建当前分类允许的内容。
- 点击一行后，在右侧填写字段。
- 使用创建副本、删除、上移和下移按钮管理内容。
- 按住每行最左侧的排序手柄拖动；蓝色插入横线表示最终位置。
- 搜索框用于查找名称、类型或 ID；旁边的类型选择用于筛选。

行顺序会影响相册、音乐、桌面应用、会话等内容在手机中的显示顺序。确实受顺序影响的项目会在右侧显示“顺序说明”。

ID 是内容之间的内部引用。建议使用稳定、简短、无空格的英文和数字，例如 `contact-lin`、`photo-01`。修改 ID 时编辑器会同步已有引用；仍被其他内容使用的对象不能直接删除。

## 编辑短信、微信和朋友圈初始内容

部分内容使用父子结构，先选择所属对象，再编辑其中的条目：

- “短信联系人与记录”：先选联系人，再编辑该联系人的初始短信。
- “会话与聊天记录”：先选微信会话，再编辑该会话的初始消息。
- “朋友圈”：先选朋友圈，再编辑它的点赞与评论。
- 日历事件按日期分组，只能在同一天内调整顺序。

新增子项会自动绑定当前父对象，不需要重复填写联系人、会话或朋友圈 ID。

## 编辑消息与对白脚本

“消息与对白”支持：

- 短信剧情
- 微信剧情
- 电话对白
- 朋友圈发布剧情
- 玩家评论剧情
- 联系人朋友圈互动剧情

左侧选择脚本，右侧填写脚本名称、所属联系人或会话等整体参数，中间区域编辑按顺序执行的消息或动作。

每个条目都可以单独收起。收起后只显示顺序、发送方或类型和内容摘要，便于集中拖动排序。发送方或消息类型改变后，编辑器只显示当前需要填写的字段。

脚本名称只用于编辑器中辨认；剧情节点引用稳定的脚本 ID。被剧情引用的脚本不能直接删除。

## 编辑剧情流程

剧情节点从左向右排列，分支在纵向展开。流程连线表示剧情先后，紫色虚线数据连线表示联系人、会话、脚本或电话对白等引用。

常用节点：

- 计时事件：激活后等待指定时间。
- 操作事件：等待玩家打开 App、内容或完成指定操作。
- 电话事件：可以按接听、拒接和未接连接不同分支。
- 关机事件：等待自身延迟后关闭手机，没有后续出口。
- 结束节点：表示一条剧情路径结束。
- 引用节点：复用联系人、会话、短信剧情、微信剧情或电话对白。

勾选“初始激活”可以建立剧情入口。一个作品可以有多个互相独立的初始入口。剧情结束不会自动关机；需要关机时，应把对应路径连接到“关机事件”。

### 画布操作

- 双击空白处、按 `Tab` 或点击“添加节点”打开节点列表。
- 从端口按住左键拖到兼容端口完成连接。
- 连线拖到空白处时，会打开只显示兼容节点的创建列表。
- 左键拖动画布空白处框选节点；`Ctrl + 左键` 增加或取消选择。
- 拖动任一已选节点时，所有已选节点一起移动。
- 鼠标中键拖动，或按住 `Space` 再左键拖动，可以平移画布。
- 滚轮以指针位置为中心缩放；鼠标位于可滚动的节点参数区时，滚轮只滚动参数。
- 双击节点的非输入区域可以展开或收起参数。
- `Ctrl + D` 创建副本，`Delete` 删除，`Ctrl + Z` / `Ctrl + Y` 撤销或重做。
- `F` 聚焦所选节点，`Home` 显示完整流程，`Esc` 取消当前操作。
- “整理节点布局”按剧情关系重新排列节点。

节点坐标、分组和折叠状态只保存在项目文件中，不会进入手机网页的运行时 JSON。

## 素材路径

图片、音频和 SVG 放在：

```text
phone-simulator/public/media/
```

字段中填写以 `/media/` 开头并带真实后缀的路径，例如：

```text
/media/photos/photo-01.jpg
/media/music/theme.mp3
/media/maps/home.svg
```

编辑器只保存路径，不会自动复制素材。配置完成后要手动把文件放入对应目录。包含素材字段的对象会在右侧显示“素材路径说明”。

普通 HEIC 文件不能只改名为 `.jpg`，需要先真正转换为 JPEG、PNG 或 WebP。锁屏和桌面壁纸留空时使用内置渐变背景。

## 保存、打开和自动恢复

编辑器使用单个 `作品名.phone-project.json` 保存作品内容和画布布局：

1. 点击“新建”并输入作品名称。
2. 第一次保存时选择文件位置。
3. 后续点击“保存”覆盖当前项目文件。
4. 点击“打开”载入已有项目。

有未保存修改时，顶部作品名称旁会显示提示。页面意外关闭后，编辑器会提供浏览器恢复副本；恢复副本只用于防止意外丢失，不能代替主动保存。

如果出现旧恢复内容，可以在提示中选择“放弃副本”。正常保存项目后，恢复副本会自动清除。

## 导入旧版 Excel

已有 Excel 作品可以一次性迁移：

1. 点击“导入 Excel”。
2. 确认替换当前项目。
3. 选择 `phone-config-template.xlsx` 或由同一模板填写的工作簿。
4. 检查导入摘要和问题列表。
5. 保存为 `.phone-project.json`。

导入会替换当前项目，不会合并已有内容。迁移完成后应继续使用项目文件，不要再让 Excel 覆盖同一作品导出的 JSON。

## 导出手机运行时 JSON

点击顶部“导出 JSON”生成：

```text
content.json
story.json
```

推荐选择：

```text
phone-simulator/src/data/
```

如果浏览器不支持直接写入文件夹，可以分别下载两份 JSON，再手动复制到上述目录。

红色错误会阻止导出；黄色警告不会阻止导出，但应确认剧情是否符合预期。导出 JSON 不会自动保存 `.phone-project.json`。

## 常见问题

- **修改后重新打开页面内容消失**：恢复副本不是正式保存，请点击“保存”或“另存为”。
- **无法直接写入文件夹**：使用最新版 Chrome 或 Edge，或改为下载 JSON 后手动复制。
- **素材无法预览**：检查文件是否位于 `phone-simulator/public/media/`，路径是否以 `/media/` 开头，以及后缀和大小写是否一致。
- **删除按钮不可用**：该内容仍被其他资源或剧情节点引用，先根据提示解除引用。
- **导出按钮被阻止**：展开底部问题列表并修正所有红色错误。
- **手机网页内容没有更新**：确认 JSON 已写入 `phone-simulator/src/data/`，然后重启网页预览。
