# PhoneSimulator 手机网页

这是 PhoneSimulator 实际运行的手机界面网页。它在浏览器中呈现锁屏、桌面和多个手机 App，并按照预先配置的内容与剧情节点响应玩家操作。

网页不需要后端、数据库或 AI 接口。内容来自 `src/data/content.json` 和 `src/data/story.json`，推荐使用[可视化编辑器](../config-editor/README.md)生成；旧作品也可以继续使用 [Excel 工具](../excel-json-tool/README.md)。

## 运行网页

需要 Node.js 22。在本目录第一次运行：

```powershell
npm install
npm run dev
```

打开终端显示的本地地址。停止预览时在终端按 `Ctrl + C`。

检查完整构建：

```powershell
npm run build
```

临时查看构建结果：

```powershell
npm run preview
```

如果修改配置后网页没有变化，请确认新的 JSON 已写入 `src/data/`，然后重启开发预览。

## 推荐的内容更新流程

1. 在可视化编辑器中打开 `.phone-project.json`。
2. 修改内容、消息脚本和剧情流程。
3. 保存项目文件。
4. 点击“导出 JSON”，选择 `phone-simulator/src/data/`。
5. 回到本目录运行 `npm run dev` 预览。
6. 确认无误后运行 `npm run build`。

不要把直接修改运行时 JSON 当作长期编辑方式。下一次从项目文件导出或运行 Excel 转换器时，手工修改会被覆盖。

## 素材目录

所有图片、头像、壁纸、封面、SVG 地图、MP3 和铃声都放在：

```text
public/media/
```

配置中填写从 `/media/` 开始、带真实后缀的路径：

```text
/media/photos/photo-01.jpg
/media/music/theme.mp3
/media/maps/home.svg
```

注意事项：

- 文件名大小写必须与配置一致。
- HEIC 需要真正转换成 JPEG、PNG 或 WebP，不能只修改扩展名。
- 大图片和音频会延长首次加载时间，建议提前压缩。
- 锁屏和桌面壁纸留空时使用内置渐变背景。
- App 图标为空或加载失败时使用内置图标。
- 闹钟没有铃声文件时使用浏览器合成音。

浏览器可能在玩家第一次点击页面前阻止声音自动播放，这是浏览器自身限制。

## 已实现的手机功能

- 锁屏、四位数字密码、桌面、动态日期、电量和天气。
- 信息、电话、微信、地图、小红书、音乐、浏览器、照片、备忘录、邮件、日历、天气、时钟、计算器和设置。
- 短信与微信剧情中的预设文字输入和玩家发送步骤。
- 来电接听、拒接、未接结果，以及主动拨号规则。
- 微信单聊、群聊、图片、表情图片、定位消息和顶部通知。
- 朋友圈点赞、取消赞、发布、评论、回复、联系人互动和多图查看。
- 相册大图切换、音乐后台播放、闹钟响铃、地图 SVG 拖动和备忘录置顶。
- 根据时间、玩家操作和电话结果推进的剧情分支。
- 独立的剧情关机事件。

## 玩家操作

- 手机界面中的返回按钮、左边缘右滑或浏览器返回可以逐层退出内容页。
- 桌面浏览器中可以按住鼠标上下拖动聊天、朋友圈和其他滚动页面。
- 移动端使用正常的触摸滚动和滑动操作。
- 相册和朋友圈大图可以左右切换。
- 顶部通知可以点击进入内容，也可以向上滑动提前关闭。

短信和微信键盘只模拟配置好的文案。玩家按键会得到视觉和声音反馈，但不能输入配置外的自由文字；点击发送按钮后才会完成对应剧情步骤。

电话接通后不能由玩家主动挂断，只能等待对白自动结束；来电接通前仍可以拒接或等待超时。

## 当前展示边界

以下入口目前只展示界面，不提供完整功能：

- 微信“通讯录”不可进入，“发现”中只有朋友圈可进入，“我”页面只展示资料。
- 微信聊天中的语音和视频通话记录只是历史气泡，不会真正发起通话。
- 浏览记录和设置不会修改真实设备或访问真实网页。
- 地图搜索、图层、定位、共享和详情收藏按钮只展示。
- 小红书只有右上角搜索按钮可用；历史记录只有配置了 `http://` 或 `https://` 链接时才能打开。
- 未特别说明可用的装饰按钮不会产生操作结果。

## 时间、电量和关机

- 固定日期留空时使用玩家本地日期；填写 `YYYY-MM-DD` 后，锁屏、桌面、日历和天气使用该日期。
- 固定日期不会改变状态栏时钟、闹钟或剧情延迟，它们仍使用玩家本地时间。
- 每格电量耗时大于 `0` 时，电量按秒数逐格降低；填写 `0` 时保持初始电量。
- 剧情结束不会自动关机。只有剧情实际进入“关机事件”时才会关闭手机，等待时间由该事件自身配置。

## 内容显示规则

- 桌面 App 是否显示由配置中的“是否使用”决定。
- 信息、邮件和微信未读角标根据实际未读内容自动计算，不需要另外填写角标数字。
- 微信会话摘要、时间和未读数取自最后一条消息。
- 备忘录置顶项显示在前面；其他项目按更新时间排列。
- 朋友圈最多支持九张图片，四张图使用 2×2 排列，更多图片最多使用 3×3 排列。
- 地图地点可以配置初始收藏、最近地点、保存日期和独立 SVG。
- 音乐配置了真实音频时优先使用音频文件自身的时长。

## 配置文件说明

手机网页读取：

```text
src/data/content.json
src/data/story.json
```

- `content.json`：基础设置、桌面应用、联系人、相册、音乐、邮件、地图、微信初始内容等。
- `story.json`：短信与微信脚本、电话对白、朋友圈脚本、主动通话规则和剧情事件图。

这两份文件由可视化编辑器或旧版 Excel 转换器生成。两种入口不能同时维护同一个作品。

## 常见问题

- **页面无法启动**：确认已经在本目录运行 `npm install`，并使用受支持的 Node.js 版本。
- **修改内容后没有变化**：重新导出或转换 JSON，再重启 `npm run dev`。
- **图片或音频加载失败**：检查文件是否在 `public/media/`，路径、大小写和后缀是否一致。
- **锁屏无法解开**：检查基础设置中的密码是否为四位数字，并确认最新 JSON 已生效。
- **没有声音**：先在页面中点击一次，再检查系统音量和素材格式。
- **剧情没有继续**：检查当前节点是否正在等待玩家打开指定内容、发送消息或完成电话结果。
- **剧情结束后没有关机**：确认剧情路径连接到了“关机事件”。
