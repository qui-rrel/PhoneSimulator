# 剧情示意地图生成器

这是一个完全离线、无需安装的 SVG 地图素材制作工具。它根据地点、地址、场景参数和随机种子生成 `1000 × 1400` 的示意地图，适合虚构地点和不要求真实导航精度的剧情场景。

## 使用方法

1. 使用最新版 Chrome 或 Edge 打开 `index.html`。
2. 填写地点名称、城市、区域、主要道路和完整地址。
3. 选择场景类型、街区密度、道路规整度、配色，以及是否生成河流和地铁站。
4. 点击“生成当前地图”，或一次生成 9 个候选方案。
5. 点击“选择输出文件夹”，建议选择本目录中的 `outputs/`。
6. 选中满意的地图，点击“保存 SVG”。

浏览器不能在未经允许时直接写入本地文件夹。权限失效后需要重新选择输出文件夹；如果当前浏览器不支持文件夹写入，保存按钮会自动改为普通文件下载。

## 使用种子复现地图

在同一生成器版本中：

```text
相同输入 + 相同种子 = 相同 SVG
```

导出的 SVG 会保存生成时的地点、地址、场景、配色、随机种子和其他参数。点击“载入 SVG”可以恢复这些参数，再继续调整和重新生成。

如果想微调同一张地图，请载入原 SVG，或保留原来的全部输入与种子。只修改种子会得到不同的道路和街区布局。

## 在 PhoneSimulator 中使用

1. 把保存的 SVG 复制到：

   ```text
   phone-simulator/public/media/
   ```

2. 在可视化编辑器或 Excel 的“地图地点”中填写路径，例如：

   ```text
   /media/maps/home.svg
   ```

3. 路径必须以 `/media/` 开头并保留 `.svg` 后缀。

不要直接引用 `map-generator/outputs/`。该目录只用于保存生成结果，不是手机网页的素材目录。

地图预览中的蓝色定位点不会写入 SVG。地点名称和主要道路会显示在 SVG 中，完整地址则保存在文件参数里，并由手机网页的地点详情单独显示。

## 常见问题

- **无法选择输出文件夹**：改用最新版 Chrome 或 Edge，或直接使用浏览器下载。
- **载入后无法恢复参数**：确认载入的是本工具生成的原始 SVG，而不是经过其他软件重新保存的文件。
- **手机网页中地图空白**：确认 SVG 已复制到 `phone-simulator/public/media/`，并检查 `/media/...svg` 路径、文件名大小写和后缀。
- **想生成完全相同的地图**：保持所有输入、随机种子和生成器版本一致。
