# PhoneSimulator Excel 配置工具

这个目录面向内容作者，用 Excel 管理手机初始内容和剧情，再由 Python 转换成网页可以读取的 JSON。写剧情的人不需要直接编辑代码或 JSON。

整个项目的安装、GitHub Desktop 备份和 Cloudflare Pages 发布步骤见[仓库总说明](../README.md)。Vue 前端功能和运行时结构见[前端说明](../phone-simulator/README.md)。

## 目录内容

```text
excel-json-tool/
├─ outputs/phone-config-template.xlsx  完整配置表与示例
├─ convert.py                          Excel 转 JSON 脚本
├─ requirements.txt                    Python 依赖
└─ README.md                           本说明
```

`phone-config-template.xlsx` 是项目内容的可读配置源，建议保留这个固定文件名并直接修改。转换结果写入：

```text
../phone-simulator/src/data/content.json
../phone-simulator/src/data/story.json
```

转换器使用脚本自身所在目录推导路径，所以整个 `PhoneSimulator` 文件夹移动或重命名后仍能工作；但 `excel-json-tool/` 和 `phone-simulator/` 必须继续保持同级。

## 第一次使用

需要 Python 3.10 或更高版本。在本目录运行：

```powershell
python -m pip install -r requirements.txt
```

安装只需完成一次。之后每次修改内容时：

1. 打开 `outputs/phone-config-template.xlsx`。
2. 按表头和顶部说明修改，保存后关闭 Excel。
3. 在本目录运行：

```powershell
python convert.py
```

4. 看到转换成功提示后，进入 `../phone-simulator/` 运行：

```powershell
npm run build
```

转换器报错时不会把错误配置当作成功结果写入。按照终端指出的工作表、行号或字段修正后重新运行即可。

## 工作表说明

工作簿包含一张总说明、13 张初始内容表和 6 张剧情表。

| 类型 | 工作表 |
| --- | --- |
| 使用说明 | 填写说明 |
| 初始内容 | 基础设置、桌面应用、相册、备忘录、闹钟、联系人、短信记录、通话记录、音乐、浏览记录、锁屏通知、邮件、日历 |
| 剧情内容 | 短信剧情、电话剧情、电话剧情内容、剧情事件、剧情分支、主动通话规则 |

表格阅读规则：

- 中文表头供内容作者阅读；同一格第二行的小号英文是对应 JSON 字段名，便于排错，请不要修改。
- 列名含“（可空）”时可以不填。
- 带下拉箭头的字段必须从选项中选择，不要手写近似文字。
- ID 用来跨表关联，必须保持唯一、稳定，并避免空格和临时中文描述。
- 数据行的显示顺序或序号决定同类内容的排列与执行顺序。
- 表格顶部的说明优先于通用说明，特别是素材路径和占位素材的优先级。

例如，短信记录和短信剧情中的“联系人 ID”必须能在“联系人”表找到；剧情事件引用的短信剧情 ID、电话对白 ID、后续事件 ID 也必须存在。转换器会检查常见的重复 ID 和缺失关联。

## 常用填写格式

### 四位锁屏密码

密码必须恰好是四位数字，例如：

```text
2799
0123
```

不能包含空格、字母或符号。若 Excel 把 `0123` 自动识别为数字 `123`，转换器会按四位密码补回开头的 `0`；超过四位或含非数字字符会报错。

### 日期、时间和秒数

- 日期：`YYYY-MM-DD`，例如 `2026-10-24`。
- 固定时间：`HH:MM`，例如 `07:30`。
- 剧情延迟、等待、超时和振铃时长：统一按秒填写，可以使用 `1.2` 这类小数。
- 动态显示玩家打开网页时的本地时间：严格填写 `LOCAL_TIME`。

`LOCAL_TIME` 可用于相册显示日期、备忘录更新时间、联系人列表时间、短信和通话记录时间、浏览记录、锁屏通知、邮件和日历显示时间。普通文字（包括“刚刚”）会原样显示；留空则不显示。

Excel 自动把日期、时间或纯数字识别为其他单元格类型通常不会影响转换，脚本会根据该列规定的格式解析，而不是依赖单元格显示类型。

### 素材路径

素材放在 `../phone-simulator/public/media/`，Excel 中填写：

```text
/media/img1.jpg
/media/song.mp3
```

必须包含文件后缀，文件名大小写和扩展名应与实际文件一致。路径素材优先；路径留空时才使用同一行配置的占位渐变、默认头像、主题色或默认铃声。

HEIC 需要先真正转换为 JPEG、PNG 或 WebP，不能只改扩展名。大体积图片和音频会显著增加网页加载时间，发布前建议压缩。

## 初始内容的关键规则

- `桌面应用`的“是否使用”控制桌面入口；组件名是代码注册值，不要随意修改。图标路径用于桌面、底部栏和通知；日历与时钟留空，由网页按玩家本地日期和时间实时绘制。其他图标路径为空或加载失败时使用代码内置图标。
- `相册`不配置图片标题；路径失败时显示占位素材。
- `联系人`保存姓名与头像；短信列表预览由程序自动取最后一条消息，并限制为一行。
- `通话记录`只通过联系人 ID 读取姓名和头像，所有记录都可以点击回拨。
- `音乐`填写 MP3 后，网页优先使用音频元数据中的真实时长；无 MP3 时使用表内时长作为演示进度。
- `锁屏通知`中电话和短信通过联系人 ID 使用联系人头像，其他通知使用对应 App 图标。
- `设置`目前只展示；用户名和 Wi-Fi 名称来自基础设置。
- `天气`的地点来自配置，天气与温度按日期和种子稳定生成。

## 短信剧情

同一个“短信剧情 ID”代表一整段剧情，一行代表界面中的一次发送或回复。“消息序号”决定先后，“发送方”可以在“我”和“对方”之间任意交替。

运行规则：

1. 剧情被激活后，连续的“对方”消息按各自行的延迟自动到达。
2. 遇到“我”时暂停。
3. 玩家打开对应聊天并点击输入框，页面才开始逐键输入预设内容。
4. 玩家必须自行点击发送；发送后继续处理后续消息。
5. 再遇到“我”就再次暂停；整段完成后才推进剧情事件。

“键盘按键序列”可空。留空时程序按消息文字生成逐字符输入序列；需要表现特殊按键过程时再填写自定义序列。

## 电话剧情和主动通话

`电话剧情`定义一段完整对白的 ID、联系人、方向和最后一句后的自动挂断等待；`电话剧情内容`按“一句一行”填写具体对白和出现延迟。同一联系人可以拥有任意多段对白。

所有通话记录都可回拨，主动拨号按以下方式选择结果：

- 没有配置主动通话规则：默认对方不接。
- 每次使用同一对白：配置一条不限制事件和拨打次数的接听规则。
- 根据剧情切换：为不同剧情事件状态分别填写规则和对白 ID。
- 有时接、有时不接：使用起始/结束拨打次数配置多条规则；不接听规则不填写对白 ID。
- 多条规则同时符合：使用规则序号最小的一条。

来电和主动拨打都会在对白最后一句显示完毕后，再等待“对白结束后挂断等待（秒）”并自动挂断。该等待用于保证玩家有时间读完最后一句。

## 剧情事件和分支

剧情没有单独的全局“线性/分支”设置。`剧情事件`定义触发方式与发生内容，`剧情分支`根据结果连接后续事件，因此一套剧情可以同时包含线性推进、不同结局和必须完成的卡点。

- 计时触发：事件激活后等待指定秒数。
- 操作触发：等待玩家打开 App、打开具体内容、进入短信输入框、拨打/接听/拒接电话等操作。
- “触发对象 ID”可对应联系人、照片、邮件、备忘录等目标。
- “仅衔接下一节点”不展示新内容，只完成本节点并连接下一事件。

`剧情分支`的“是否重试”为“否”时，重试结果单元格即使有内容也会被忽略；为“是”时至少填写一项。当前电话结果只允许“接听”“拒接”“未接”，多个结果必须在同一个单元格中用 `Alt + Enter` 换行，一行一个，不使用逗号、顿号或 `||`。

## 指定其他文件

默认命令读取示例工作簿并写入前端数据目录。需要测试另一份工作簿或只导出到临时位置时可以使用：

```powershell
python convert.py --input .\outputs\another-config.xlsx --out-dir .\json-output
```

指定路径时仍建议先备份目标 JSON。正式项目内容建议始终回写默认位置，避免网页仍在读取旧文件。

## GitHub 备份注意事项

推荐把 `excel-json-tool/` 与 Vue 项目一起提交到外层 `PhoneSimulator` 仓库。正式 `.xlsx` 文件会进入 Git 历史，便于回退；Cloudflare 只构建 `phone-simulator/`，不会把 Excel 发布到网页。

不要同时维护第二份手工复制的工作簿，否则容易出现版本不一致。Excel 打开时生成的 `~$*.xlsx` 临时文件已经在仓库根目录的 `.gitignore` 中排除。

如果你正在编辑工作簿但尚未转换，Excel 与 JSON 暂时不一致是正常现象。提交前是否运行转换取决于这次提交是“只备份表格草稿”还是“发布网页内容”；需要发布时必须转换并编译。

## 常见问题

- **提示文件被占用**：保存并完全关闭 Excel 后再运行转换。
- **密码正确但无法解锁**：确认转换成功，且网页使用的 `content.json` 已更新；重新构建或重启本地预览。
- **素材显示空白**：检查文件是否在 `public/media/`、路径是否以 `/media/` 开头、后缀是否真实可解码，以及大小写是否一致。
- **修改 Excel 后网页没变化**：先运行 `python convert.py`，再运行 `npm run build` 或重启开发服务。
- **脚本找不到前端目录**：确认 `excel-json-tool/` 和 `phone-simulator/` 仍然是同级目录。
