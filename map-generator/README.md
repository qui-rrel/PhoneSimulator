# 剧情示意地图生成器

这是一个完全离线、无需安装的静态地图素材制作工具。它根据地点、地址、场景参数和随机种子生成 `1000 × 1400` 的 SVG 示意地图，适合为虚构地点或不要求导航准确性的剧情地点制作地图背景。

工具与 `phone-simulator/`、Excel 转换器和网页运行时相互独立。可以直接把整个 `map-generator/` 文件夹发给剧情策划使用。

## 使用方法

1. 使用最新版 Chrome 或 Edge 双击打开 `index.html`。
2. 填写地点名称、城市、区域、主要道路和完整地址。
3. 选择场景类型、街区密度、道路规整度，以及是否生成河流和地铁站。
4. 点击“生成当前地图”，或一次生成 9 个候选。
5. 点击“选择输出文件夹”，选择本目录下的 `outputs/`。
6. 选中满意的地图后点击“保存 SVG”。

浏览器不允许网页在未经授权的情况下直接写入本地文件夹，所以每次权限失效后需要重新选择 `outputs/`。如果浏览器不支持文件夹写入，保存按钮会自动退化为普通浏览器下载。

## 确定性与重新编辑

地图生成不使用 `Math.random()`、当前日期或当前时间。相同生成器版本中：

```text
相同输入 + 相同种子 = 完全相同的 SVG
```

导出的 SVG 在 `<metadata id="map-generator-data">` 中保存：

- 生成器版本；
- 随机种子；
- 地点、城市、地址和主要道路；
- 场景、配色、密度和规整度；
- 河流、地铁和站点设置；
- 画布尺寸和目标点坐标。

点击“载入 SVG”可恢复这些参数并继续编辑。生成器版本会随文件保存；未来新增算法时应增加版本号，不要改变旧版本相同种子的结果。

## 文件与运行时使用

正式输出建议使用 SVG。它适合地图线条和文字，缩放清晰，文件体积通常也比同尺寸 PNG 小。

生成后的文件先保存到 `outputs/`。要在 PhoneSimulator 中使用时，再把选中的 SVG 复制到网页项目的公开素材目录，并在 Excel 中填写对应的 `/media/...svg` 路径。不要在运行时网页中引用 `map-generator/outputs/`。

地图中的蓝色定位点仅存在于工具预览层，不会写入 SVG。SVG 自身包含地点名称和主要道路名称；完整地址保存在 metadata 中，方便未来地图 App 的详情卡片读取或人工配置。

## 目录结构

```text
map-generator/
├─ index.html          工具页面
├─ styles.css         页面样式
├─ map-core.js        确定性 SVG 生成核心
├─ generator.js       表单、候选、载入和保存逻辑
├─ tests/run-tests.js Node 结构与确定性测试
└─ outputs/           默认建议选择的输出目录
```

运行测试：

```powershell
node .\tests\run-tests.js
```

测试不需要安装 npm 依赖。
