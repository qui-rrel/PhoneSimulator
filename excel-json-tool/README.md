# PhoneSimulator 旧版 Excel 配置工具

本工具用于继续兼容已经使用 Excel 制作的 PhoneSimulator 作品。作者在工作簿中填写手机内容和剧情，再通过 Python 转换成网页读取的 `content.json` 与 `story.json`。

新作品推荐使用[可视化编辑器](../config-editor/README.md)。已有 Excel 作品可以继续使用本工具，也可以一次性导入可视化编辑器后迁移。

同一个作品不要同时维护 Excel 和 `.phone-project.json`。两种方式会覆盖相同的运行时 JSON，不会自动合并或双向同步。

## 文件说明

```text
excel-json-tool/
├─ outputs/phone-config-template.xlsx  旧版兼容工作簿
├─ convert.py                          Excel 转 JSON 工具
├─ requirements.txt                    Python 依赖
└─ README.md                           本说明
```

转换结果写入：

```text
phone-simulator/src/data/content.json
phone-simulator/src/data/story.json
```

请保留 `excel-json-tool/` 和 `phone-simulator/` 的相对位置。如果整体移动项目，应一起移动整个 `PhoneSimulator` 文件夹。

## 安装

需要 Python 3.10 或更高版本。第一次使用时，在本目录运行：

```powershell
python -m pip install -r requirements.txt
```

手机网页还需要 Node.js 22。第一次运行网页时，在 `phone-simulator/` 执行 `npm install`。

## 标准使用流程

1. 打开 `outputs/phone-config-template.xlsx`。
2. 按表头和每张表顶部的说明填写内容。
3. 保存并完全关闭 Excel。
4. 在 `excel-json-tool/` 运行：

   ```powershell
   python convert.py
   ```

5. 转换成功后，进入手机网页目录预览：

   ```powershell
   Set-Location ..\phone-simulator
   npm run dev
   ```

6. 检查完整构建：

   ```powershell
   npm run build
   ```

转换失败时不会把错误数据当作成功结果写入。根据终端提示的工作表、行号和字段修正后，重新运行即可。

## 工作表分类

| 类型 | 工作表 |
| --- | --- |
| 使用说明 | 填写说明 |
| 基础与初始内容 | 基础设置、桌面应用、相册、备忘录、闹钟、联系人、短信记录、通话记录、音乐、浏览记录、锁屏通知、邮件、日历、地图地点、小红书搜索记录 |
| 剧情 | 短信剧情、电话剧情、电话剧情内容、剧情事件、剧情分支、主动通话规则、主动通话条件 |
| 微信初始内容 | 微信账号、微信联系人、微信群聊、微信群成员、微信会话、微信消息、朋友圈、朋友圈点赞、朋友圈评论 |
| 微信剧情 | 微信剧情、朋友圈发布剧情、朋友圈玩家评论剧情、朋友圈互动剧情 |

不使用的内容表可以只保留表头，但不要删除工作表、表头、下拉选项或英文系统字段。

## 推荐填写顺序

按下面的顺序填写，可以减少 ID 关联错误：

1. **基础设置**：网页名称、手机尺寸、密码、电量、主人资料、主题、壁纸和天气。
2. **桌面应用**：决定显示哪些 App、顺序、图标和底部栏位置。不要修改组件名。
3. **基础对象**：联系人、微信账号、微信联系人、群聊、微信会话和地图地点。
4. **初始内容**：短信记录、相册、备忘录、闹钟、音乐、邮件、日历、朋友圈等。
5. **剧情脚本**：短信剧情、微信剧情、电话对白和朋友圈脚本。
6. **剧情事件与分支**：设置初始事件、触发方式、发生内容和后续节点。
7. **转换检查**：关闭 Excel，运行 `python convert.py`，再预览手机网页。

建议先完成一条可以从初始事件走到结束的主线，再添加来电分支、重试和支线。

## 基本填写规则

- 中文表头供作者阅读；同一格第二行的小号英文是系统字段，不要修改。
- 带“可空”的字段可以留空；其他必填字段不能使用空格、`-`、`无`或 `null` 代替。
- 带下拉箭头的字段必须从列表中选择，不要手写近义词。
- ID 必须唯一、稳定，建议使用无空格的英文、数字和短横线。
- 序号决定同一组内容的显示或执行顺序，不等于 ID。
- 数字 `0` 与空白含义不同。等待时间为 `0` 表示立即执行；每格电量耗时为 `0` 表示电量保持不变。
- 多个图片路径或多个重试结果使用 `Alt + Enter` 在同一单元格内换行，一行一项。
- “微信账号”必须且只能有一行；玩家自己的微信 ID 固定使用 `SELF`。

## ID 和引用

ID 用于连接不同工作表，不会直接显示给玩家。建议使用类似以下格式：

```text
contact-lin
wx-conversation-home
sms-opening
dialogue-call-01
event-start
```

主要关联关系：

| 填写位置 | 必须先存在于 |
| --- | --- |
| 短信记录、短信剧情、电话剧情、通话记录中的联系人 ID | 联系人 |
| 微信单聊目标、消息发送人 | 微信联系人；玩家自己填写 `SELF` |
| 微信群成员中的群聊 ID | 微信群聊 |
| 微信消息、微信剧情中的会话 ID | 微信会话 |
| 定位消息中的地图地点 ID | 地图地点 |
| 朋友圈点赞、评论、互动中的朋友圈 ID | 朋友圈或将要生成该朋友圈的发布剧情 |
| 剧情事件引用的脚本 ID | 对应短信、微信、朋友圈剧情或电话剧情 |
| 剧情分支、主动通话条件中的事件 ID | 剧情事件 |
| 评论回复对象 ID | 同一朋友圈下已经存在或将要生成的评论 |

显示名称可以以后修改；已经被其他表引用的 ID 不要随意更改。

## 常用格式

### 四位密码

锁屏密码必须是四位数字，例如：

```text
2799
0123
```

如果 Excel 把 `0123` 显示为 `123`，转换器会按四位密码补回前导零；超过四位或包含非数字字符会报错。

### 日期和时间

- 日期：`YYYY-MM-DD`，例如 `2026-10-24`。
- 时间：`HH:MM`，例如 `07:30`。
- 剧情延迟、等待和超时统一按秒填写，可以使用 `1.2` 这样的小数。
- 动态显示玩家打开网页时的本地时间：填写严格大写的 `LOCAL_TIME`。
- 固定日期留空时使用玩家本地日期；填写后只固定锁屏、桌面、日历和天气的年月日。
- 初始电量填写 1～100 的整数。
- 每格电量耗时填写非负整数；`0` 表示电量保持初始值。

普通文字“刚刚”会原样显示，不代表动态时间。

### 素材路径

把图片、音频和 SVG 放入：

```text
phone-simulator/public/media/
```

Excel 中填写以 `/media/` 开头、带真实后缀的路径：

```text
/media/photos/photo-01.jpg
/media/music/theme.mp3
/media/maps/home.svg
```

填写路径不会自动复制素材，需要手动把文件放入对应目录。文件名大小写和后缀必须与实际文件一致。HEIC 需要真正转换为 JPEG、PNG 或 WebP，不能只修改扩展名。

锁屏和桌面壁纸留空时使用内置渐变背景；其他素材留空或加载失败时会尽量使用默认图标、占位内容或合成铃声。

## 初始内容要点

- “网页名称”只控制浏览器标签页标题，不显示在手机界面中。
- “桌面应用”的“是否使用”控制入口是否显示；组件名不要修改。
- 日历和时钟图标路径可以留空，它们会按日期和时间动态绘制。
- 信息、邮件和微信未读角标由未读内容自动计算，不需要在桌面应用表中填写。
- 备忘录置顶项显示在前面；其他项目按更新时间排列。
- 联系人列表预览自动使用最后一条短信。
- 地图地点的 SVG 路径必须是 `/media/...svg`。
- 小红书搜索链接可以留空；填写时必须以 `http://` 或 `https://` 开头。
- 音乐配置了 MP3 时，网页优先使用音频文件自身的时长。
- 锁屏通知中的电话和短信使用联系人头像，其他通知使用 App 图标。

## 微信配置要点

- 微信联系人和电话/短信联系人是两套独立数据。
- 每个群必须包含玩家自己 `SELF`；群头像由群成员头像自动拼合。
- 联系人或群存在但没有建立微信会话时，不会出现在聊天列表中。
- 微信会话摘要、时间和未读数从最后一条消息自动计算。
- 微信消息支持文字、图片、表情图片、定位和只用于展示的语音/视频通话记录。
- 定位消息需要同时填写定位卡片图片路径和地图地点 ID。
- 朋友圈最多九张图片，使用 `Alt + Enter` 一行填写一张。
- 朋友圈评论支持文字和最多一张图片，二者至少填写一项。
- 玩家发布、评论和回复的可发送内容由对应剧情脚本决定，不是自由输入。

## 短信和微信剧情

同一个剧情 ID 表示一整段消息流程，一行表示一次发送或回复，序号决定先后。

运行方式：

1. 连续的对方消息按各自延迟自动到达。
2. 遇到玩家消息时暂停。
3. 玩家打开对应聊天并点击输入框后，页面逐键输入预设文案。
4. 玩家点击发送后继续。
5. 整段完成后，剧情事件才进入后续节点。

键盘按键序列可以留空，程序会从消息文字生成默认输入过程。Emoji 直接写在消息中，不需要写进按键序列。

## 电话剧情和主动通话

“电话剧情”定义一段完整对白的 ID、联系人、方向和自动挂断等待；“电话剧情内容”按一句一行填写对白和延迟。同一联系人可以有多段不同对白。

主动通话规则可以按拨打次数和剧情事件状态决定是否接听以及使用哪段对白：

- 没有匹配规则时默认无人接听。
- 同一规则中的多个条件必须全部满足。
- 需要“或”关系时，建立多条不同规则。
- 多条规则同时符合时，使用规则序号更小的一条。

电话接通后玩家不能主动挂断；对白结束后按照配置的等待时间自动关闭通话页面。

## 剧情事件和分支

“剧情事件”定义触发方式和发生内容，“剧情分支”连接后续事件。

- 计时触发：事件激活后等待指定秒数。
- 操作触发：等待玩家打开 App、内容、输入框或完成电话操作。
- 仅衔接下一节点：不展示新内容，只推进到后续事件。
- 手机关机：等待本事件的触发延迟后关机，没有后续事件。

剧情完成本身不会自动关机。需要关机时，把相应结局路径连接到“手机关机”事件，并在该事件中填写等待时间。

来电事件可以按接听、拒接和未接连接不同分支。未进入的分支不会执行，也不会阻止其他剧情继续。

## 迁移到可视化编辑器

1. 启动 `config-editor/`。
2. 点击“导入 Excel”。
3. 选择当前工作簿并检查导入结果。
4. 保存为 `.phone-project.json`。
5. 后续继续打开项目文件编辑和导出 JSON。

迁移是一次性的，不是同步功能。迁移后不要再让旧 Excel 覆盖同一作品的运行时 JSON。

## 指定其他输入或输出位置

默认命令读取兼容工作簿并写入手机网页数据目录。临时测试其他工作簿时可以使用：

```powershell
python convert.py --input .\outputs\another-config.xlsx --out-dir .\json-output
```

## 常见问题

- **提示文件被占用**：保存并完全关闭 Excel，再运行转换。
- **提示工作表缺失**：恢复被删除或改名的工作表；不使用时只清空数据行。
- **提示 ID 不存在**：先在对应基础表创建该 ID，再检查拼写和空格。
- **密码正确但无法解锁**：确认转换成功，并重启手机网页预览。
- **素材显示空白**：检查文件位置、`/media/` 路径、大小写和真实后缀。
- **修改 Excel 后网页没有变化**：重新运行 `python convert.py`，再重启 `npm run dev`。
- **找不到手机网页目录**：确认 `excel-json-tool/` 与 `phone-simulator/` 仍然处于同一项目目录下。
